# Next Move

Local-first Personal Daily Execution Coach that helps choose the next action.

## Run locally

Prerequisites:

- [Android Studio](https://developer.android.com/studio)
- Android SDK Platform 36.1
- JDK 17 or newer

1. Open this project in Android Studio and install SDK 36.1 if prompted.
2. Run the `app` configuration on an emulator or physical device.
3. From a terminal, run the project's Gradle wrapper:

   ```sh
   ./gradlew testDebugUnitTest lintDebug assembleDebug
   ```

   On Windows PowerShell, run:

   ```powershell
   .\gradlew.bat testDebugUnitTest lintDebug assembleDebug
   ```
